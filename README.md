# IPSW 自動下載器 — 安裝檔下載

這裡只放「IPSW 自動下載器」的安裝檔，供下載與 App 內的「檢查更新」使用。

## 下載

到 [Releases](https://github.com/samwang38/ipsw-auto-downloader-releases/releases/latest) 下載最新的 `IPSW-Auto-Downloader-…-macOS12-universal.dmg`。

- 支援 macOS 12 Monterey 以上，Intel 與 Apple Silicon 都可以用。
- 安裝與使用方式請看每個版本附的 `INSTALL.zh-TW.md`。
- `SHA256SUMS.txt` 是檔案的檢查碼，App 更新時會用它確認下載的檔案沒有損壞。

## 這個 App 做什麼

每天在你設定的時間，自動檢查並下載勾選的 iPhone／iPad 機型最新版 IPSW 韌體到指定資料夾。韌體由 Apple 伺服器提供，這裡不包含任何 IPSW 韌體。

## 注意

App 使用本機簽章，沒有經過 Apple Developer ID 公證。第一次開啟時 macOS 可能會提示無法確認開發者，請依安裝說明允許開啟。
